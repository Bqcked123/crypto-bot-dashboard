# Crypto bot dashboard (paper trading)

Pretend money only. This is a read-only, static copy of a holographic dashboard for a set of paper-trading crypto bots.

- Page: https://bqcked123.github.io/crypto-bot-dashboard/
- Live data: the `data` branch (`data.json`), refreshed every few minutes. The page polls it every 60 seconds and falls back to the snapshot bundled here.
- 3D rendering uses three.js from the jsDelivr CDN.

Nothing here is financial advice.
